# End-to-End Data Pipeline: Online Job Vacancy Web Scraper & Cleaner

## Project Overview
Online job vacancy data is notoriously messy. Raw website data often contains inconsistent text, duplicate listings, and completely unformatted salary data. 

This project demonstrates a full **End-to-End Data Pipeline**. I used **Python** in Google Colab to extract raw vacancy data directly from a source website, then leveraged **Excel Power Query** to handle the ETL (Extract, Transform, Load) process, manage the data structure, and standardize columns for visualization.

## Tech Stack
* **Data Extraction:** Python (Google Colab), Pandas
* **Data Transformation & Management:** Excel Power Query
* **Data Visualization:** Excel Dashboards

## Core Pipeline Steps

### 1. Web Scraping & Data Extraction (Python)
* Connected to the source website using Python scripts in Google Colab.
* Extracted the raw HTML data and converted it into a structured tabular format using Pandas.
* Exported the raw, uncleaned dataset to Excel for transformation.

### 2. Data Cleansing & Standardization (Excel Power Query)
* **Salary Standardization:** Handled the messiest column by using data formatting functions to turn irregular text into clean, standardized numerical columns.
* **Data Quality:** Removed duplicate postings, filtered out missing values, and standardized text data.
* **Data Management:** Adjusted data types to ensure the dataset was completely optimized for analysis and dashboarding.

## Key Insights & Takeaways
By building this pipeline, I successfully transformed a chaotic, unreadable web dataset into a clean, structured, and production-ready data model.
